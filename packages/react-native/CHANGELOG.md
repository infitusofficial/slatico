# Changelog

## 0.1.0

- Initial public release preparation of `@slatico/react-native` for **Slatico by Infitus Creative Studio**.
- Native `react-native-svg` components for all 27 Tier 1 icon families across all 7 official styles (`189` style-specific components + `27` unified `<NameIcon variant="..." />` components).
- Supports subpath imports (`@slatico/react-native/icons/<slug>`), Duotone customization (`color`, `secondaryColor`, `secondaryOpacity`), dual-color `Color` customization (`color`, `secondaryColor`), and VoiceOver/TalkBack `title` / `accessibilityLabel`.
