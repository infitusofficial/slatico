# Changelog

## 0.1.0

- Initial public release preparation of `@slatico/core` for **Slatico by Infitus Creative Studio**.
- Core TypeScript types, style specifications, naming utilities, and generated catalog metadata for all 27 Tier 1 production icon families across all 7 official styles (`189` total variants: `thin`, `light`, `regular`, `bold`, `fill`, `duotone`, and `color`).
