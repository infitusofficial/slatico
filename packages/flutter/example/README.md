# `slatico_icons` Example Application

Interactive Flutter showcase demonstrating all **27 Tier 1 Slatico icon families** across all **7 official styles** (`Thin`, `Light`, `Regular`, `Bold`, `Fill`, `Duotone`, and `Color`), including live search, style switching, size scaling, and Duotone secondary color/opacity controls.

## Running the Example

```bash
cd packages/flutter/example
flutter pub get
flutter run
```
