# Changelog

## 0.1.0

- Initial public release preparation of `@slatico/web` for **Slatico by Infitus Creative Studio**.
- Framework-agnostic `<slatico-icon>` Custom Element with Shadow DOM encapsulation and tree-shakeable icon registration (`registerSlaticoIcons`) for all 27 Tier 1 icon families across all 7 official styles (`189` variants).
- Supports reactive attributes (`name`, `variant`, `size`, `color`, `secondary-color`, `secondary-opacity`, `label`) and SSR markup generation (`buildSlaticoWebElementMarkup`).
