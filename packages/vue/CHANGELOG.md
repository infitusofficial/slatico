# Changelog

## 0.1.0

- Initial public release preparation of `@slatico/vue` for **Slatico by Infitus Creative Studio**.
- Tree-shakeable Vue 3 render-function components for all 27 Tier 1 icon families across all 7 official styles (`189` style-specific components + `27` unified `<NameIcon variant="..." />` components).
- Supports subpath imports (`@slatico/vue/icons/<slug>`), SSR-safe `useId()` ID scoping, Duotone customization (`color`, `secondaryColor`, `secondaryOpacity`), and dual-color `Color` customization (`color`, `secondaryColor`).
