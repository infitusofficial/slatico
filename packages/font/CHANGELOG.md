# Changelog

## 0.1.0

- Initial public release preparation of `@slatico/font` for **Slatico by Infitus Creative Studio**.
- Compiles all 27 Tier 1 icon families across the 5 monochrome styles (`thin`, `light`, `regular`, `bold`, `fill`) into 5 font families (`135` glyphs total) in `WOFF2`, `WOFF`, and `TTF` formats.
- Provides deterministic Private Use Area (`U+E001`–`U+E01C`) codepoints (`codepoints.json`), `slatico.css` stylesheet (`slatico slatico-<name>-<style>`), and typed helper utilities (`getFontClassName`, `getFontGlyph`, `getFontHtmlSnippet`).
