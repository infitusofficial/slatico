# `@slatico/react`

> **Status:** Implemented (Phase 1 Foundation — Local Build Verified, Not Yet Published to npm).

Official tree-shakeable React icon components for **Slatico by Infitus Creative Studio**, supporting all 7 styles (`thin`, `light`, `regular`, `bold`, `fill`, `duotone`, `color`), Duotone secondary tone customization (`secondaryColor`, `secondaryOpacity`), and direct subpath imports (`@slatico/react/icons/<name>`).
