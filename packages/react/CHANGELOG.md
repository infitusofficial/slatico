# Changelog

## 0.1.0

- Initial public release preparation of `@slatico/react` for **Slatico by Infitus Creative Studio**.
- Tree-shakeable React 18 & 19 SVG components for all 27 Tier 1 icon families across all 7 official styles (`189` style-specific components + `27` unified `<NameIcon variant="..." />` components).
- Supports subpath imports (`@slatico/react/icons/<slug>`), `forwardRef`, SSR-safe `useId()` ID scoping, Duotone customization (`color`, `secondaryColor`, `secondaryOpacity`), and dual-color `Color` customization (`color`, `secondaryColor`).
